## 🎯 Quick Start Deployment (3 Steps)

### Step 1: Get the Code on GitHub

**Option A: Upload via GitHub Web Interface** (Easiest - No technical skills needed)

1. Go to https://github.com and sign in (or create free account)
2. Click the **"+"** button (top right) → **"New repository"**
3. Name it: `yourlocalmortgagepro-website`
4. Make it **Public**
5. Click **"Create repository"**
6. Click **"uploading an existing file"** link
7. **Drag and drop ALL the files from this folder** into the upload area
8. Click **"Commit changes"**

**Option B: Use GitHub Desktop** (If you prefer a visual tool)

1. Download GitHub Desktop: https://desktop.github.com
2. Install and sign in
3. Click **"File"** → **"New Repository"**
4. Name: `yourlocalmortgagepro-website`
5. Choose the location (this folder)
6. Click **"Create Repository"**
7. Click **"Publish repository"** (top right)

---

### Step 2: Deploy to Vercel (The Free Hosting)

1. Go to https://vercel.com
2. Click **"Sign Up"** → Choose **"Continue with GitHub"**
3. After signing in, click **"Add New..."** → **"Project"**
4. Find `yourlocalmortgagepro-website` in the list
5. Click **"Import"**
6. **Don't change any settings** - just click **"Deploy"**
7. Wait 2-3 minutes while it builds...
8. **DONE!** Your site is live! 🎉

You'll get a free URL like: `yourlocalmortgagepro.vercel.app`

---

### Step 3: Connect Your Custom Domain (Optional)

If you own `yourlocalmortgagepro.com`:

1. In Vercel, go to your project → **"Settings"** → **"Domains"**
2. Type your domain name and click **"Add"**
3. Vercel will show you DNS records to add
4. Log in to your domain registrar (GoDaddy, Namecheap, etc.)
5. Add the DNS records Vercel shows you
6. Wait 24-48 hours for DNS to propagate

**Your site will then be live at yourlocalmortgagepro.com for FREE!**

## 🎨 How to Make Updates

### Update Text or Images

1. Go to your GitHub repository
2. Navigate to the file you want to edit (e.g., `src/pages/index.astro`)
3. Click the **pencil icon** (Edit this file)
4. Make your changes
5. Scroll down and click **"Commit changes"**
6. **Vercel automatically rebuilds your site in ~2 minutes!**

### Update Colors or Styling

Edit `tailwind.config.mjs`:
```javascript
colors: {
  primary: {
    cyan: '#00BCD4',      // Change these hex codes
    magenta: '#E91E63',   // to update your brand colors
    black: '#1a1a1a',
  },
}
```

## 🆘 Troubleshooting

**Build fails on Vercel?**
- Check that all files uploaded correctly
- Make sure `package.json`, `astro.config.mjs`, and `tailwind.config.mjs` are in the root folder

**Site looks broken?**
- Clear your browser cache (Ctrl+Shift+R or Cmd+Shift+R)
- Wait 2-3 minutes after deploying

**Images not showing?**
- Make sure `dennis-headshot.png` and `logo.png` are in the `public/` folder
